# 产品范围基线

日期：2026-10-13。状态：Accepted（设计已确定，能力尚未实现）。实施顺序见 [迭代路线图](../iterations/README.md)，职责见 [模块边界](../architecture/boundaries.md)，通过条件见 [门禁](../architecture/gates.md)。

## 产品与用户边界

完整文生视频短剧创作工作台，分阶段实现；一次部署支持多个用户，每个用户管理自己的私有项目。Project 包含 Episode，一集包含 Scene/Shot；Episode 不表示重试或版本。

开发成员共同维护仓库，与产品用户协作不是同一概念。首期没有组织、团队成员邀请、多人共享编辑或实时协同。

当前按用户答复先本地运行，约1000是注册用户总量规划，不是同时在线/生成。评审后的规格/额度/保留默认值见 [ADR-005](../adr/ADR-005-coding-baseline.md)，第一轮仅实现 [I002基础交付](../iterations/I002-foundation.md)。

## 当前规格与运行默认值

- 首期写实、9:16/720p，默认60秒，主验收30～60秒，产品上限120秒；最多30 Shot/集、6主要角色/项目、2对白角色同镜头轮流，均可配置。真实支持必须取Provider实测交集，1080p和其他风格后续。
- 人民币账本；用户UTC自然月¥100，项目/集/Run累计各¥100同时约束不相加；无Run前置调用检查所属额度与单操作¥100。累计测试预算无总上限，不授权无限重试或本轮立即付费。
- 本地Compose，无云采购；项目10GiB、实例素材50GiB为保护目标，不代表1000用户生产容量。每日备份、RPO≤24h/RTO≤4h为待验证演练目标。
- 媒体默认30天，显式延期；到期将相关使用根标EXPIRED，按引用释放/运行保护清理，历史快照保留但不承诺过期素材永久可播放。未知费用与必要审计单独核对，期限发布前确定。
- 初期管理员与最终审核/运行决策由用户承担，Agent辅助；真实运营反馈时间、协作分工、审核政策明细发布前确定。

## 首期能力

| 范围 | 用户能力及约束 |
|---|---|
| 身份与项目 | 邮箱/密码、Session、项目归属；无真实邮件时生产采用管理员邀请，公开注册须通过身份发布门禁 |
| 创作 | 输入故事、生成/编辑剧本与分镜；确认当前版本后才推进下一创作阶段 |
| 角色对白 | 首期普通话剧情短剧，画内口型同步；单角色/同镜头多角色轮流说话，台词逐字保留；项目角色形象与预设声音跨镜头/集一致，每句表演可变化 |
| 生成 | 参考素材、角色/场景、Keyframe、Shot 视频；能力不支持时明确拒绝，禁止静默降级 |
| 版本 | 草稿、不可变确认版本、GenerationRun、候选结果与选用结果；保留历史，不自动覆盖已选用结果 |
| 控制 | 查看进度、失败原因、取消、恢复和单 Shot 重生成；展示依赖影响及预计费用 |
| 审核 | 自动质量与安全检查；用户复核自身素材质量，管理员处理授权范围内的安全复核 |
| 音频与成片 | 对白 TTS 先生成并校验实际时长，再分镜；联合试听确认、跨镜头连续音轨/字幕、口型、简单排序/裁剪、FFmpeg 成片；无对白镜头可存在。成片以灵活、真实、自然的叙事与表演节奏为质量目标，不为把台词与 Shot 一一对应而机械切镜 |
| 可靠性 | 幂等、预算预占、恢复、私有存储、可追溯日志、部署、备份恢复 |

首期排除支付/充值、组织协作、高级多轨拖拽剪辑、自动配乐、完全自主 Agent、长期自主记忆、自动模型路由、任意远程 URL 素材导入，以及抢话/同时说话/合唱、样音定制、方言/多语言、旁白故事短片。平台保留明确扩展接口，不建立未使用的复杂扩展框架。

## 操作语义

- 默认：生成剧本→确认台词→角色声音/表演与真实语音准备→按实际时长规划分镜与对白→用户联合试听确认→视频/口型生成与审核→最终 Timeline/字幕/渲染；失败/人工复核/输入过期时暂停。详见 [音画架构](../architecture/dialogue-timeline.md)。
- 声音时间与已确认的表演意图优先于机械镜头对应：台词可跨镜头，镜头可容纳多句或为听者反应、动作、环境服务；自然停顿、画内/画外切换和连续对白均须在规划中显式表达。此质量目标由已实测自动策略或人工复核给出证据，不预设未经验证的自动分数阈值。
- 草稿编辑不修改运行中快照；同Run首次确认后续阶段正常追加快照，替换已确认/执行输入才新Run并标下游待更新。一个Episode同时一个活动完整Run，独立Shot活动意图和选用revision也受并发控制。
- “恢复”：继续同一输入与批次的可恢复步骤；“重生成”：显式创建新的生成版本/任务并重新预占预算；“选用”：更新素材选择并计算依赖失效。三者不能共用模糊的重试按钮。
- 候选素材先做媒体、质量、安全检查，合格后才能选用；首次仅可按已实测策略自动选用，需要自然度/镜头衔接人工复核的候选须先完成复核；已有选用版本时由用户确认替换。全阶段门禁检查选用素材集合。
- 输入已变化、取消或删除后的晚到结果保留来源记录，不能覆盖当前选择或恢复流程。历史 Render 固定引用，不随编辑变化。
- FAILED可显式续办复用原输入/结果；CANCELLED不得自动续办，须明确新意图。请求幂等不阻止主动重生成同文本的新候选；新付费调用独立预占。

## 未定参数与决策截止点

| 参数 | 确定方式与截止点 | 未确定时 |
|---|---|---|
| Provider真实支持规格 | 产品目标已见上节，真实能力取实测交集；生成前核对 | 可开发Mock，不承诺目标规格已支持 |
| 预设音色列表、对齐实现、编码规格与同步容差 | 普通话/预设音色方向已确定，具体 Provider 和效果实测；视频/口型提交前固定 | 不宣称对应能力可用 |
| Provider、并发、超时、实际费用上界 | 额度初值已确定；接入测试/报价/具体调用计划仍需明确 | 无真实账号/费用证据不得调用 |
| 审核阈值与硬阻断策略 | 样本评估、管理员授权流程；真实内容自动放行前确定 | 人工复核，不按缺配置默认通过 |
| 清理和容量/恢复验证 | 30天及本地容量/恢复目标已确定；引用保护、实测/演练发布前通过 | 清理未实现/测试不启用；不承诺生产容量/恢复SLA |

这些参数可后续通过研究和 ADR 确定，不阻塞基础工程；不得由实现者随意填值并视为已验证。

## 范围验收

关键流程须通过 Mock 全链及受控预算真实链；用户能追溯成片的剧本、分镜、素材和生成输入。权限、预算、取消、版本与恢复按门禁验收。分阶段完成不代表完整产品已可上线，最终发布须满足工程门禁。
