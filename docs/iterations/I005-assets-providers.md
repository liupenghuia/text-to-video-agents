# I005：素材与真实 Provider

状态：Planned。真实调用前必须通过 [门禁](../architecture/gates.md) E03 及相应业务门禁；Provider 能力以实测交集为准。

- [ ] Mock 支持成功/失败/超时/重复回调；Mock 视频输出真实可探测媒体，不只返回假 URL。
- [ ] 调研并选择首个通过合约测试的 LLM、图片、视频、TTS、lip-sync、审核 Provider；记录官方来源、日期、成本、商用与实测证据。
- [ ] 实现参考素材上传、媒体归档、下载限制、候选版本、单 Shot 重生成及依赖处理。
- [ ] 接真实 TTS/可信对齐，按时间交集调度口型并保存上下文/裁剪映射；不支持时阻断并提供用户确认的正反打方案。

验收：归档、幂等、预算、下载恢复通过；普通配音不算口型；固定台词/说话人/声音/单多角色同步实测，无静默降级。
