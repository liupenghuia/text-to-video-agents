# 业务与工程门禁

日期：2026-10-13。状态：Accepted（设计已确定；所有执行器和测试尚待实现）。关联 [范围](../product/scope.md)、[边界](./boundaries.md)、[TODO](../../todo.md)。

## 统一执行约定

每次门禁求值记录 gateId、runId、目标版本、策略版本、证据引用与求值时间，返回 PASS / BLOCKED / WAITING / NOT_REQUIRED，以及稳定原因码和允许的恢复动作。NOT_REQUIRED 仅用于有明确依据的可选步骤（如无对白），不是异常降级手段。

- 授权、预算、版本与并发在服务端检查；前端禁用按钮只是提示。
- 阶段完成信号触发重新检查；在提交迁移时事务内校验 revision/取消/删除与唯一推进键，避免检查后输入被替换。
- 未完成依赖返回 WAITING，明确违规/过期/缺配置返回 BLOCKED；处理异常不得按 PASS。
- 候选素材审核发生在选用之前；阶段聚合门禁检查被选用的具体版本。旧审核不能适用于新素材。
- 没有测试证据时文档状态只是“设计 Accepted”，不能标记门禁已落实。
- 同Run首次确认后续阶段正常推进；替换已确认/执行快照才新Run。失败续办、取消与请求幂等按 [ADR-005](../adr/ADR-005-coding-baseline.md) 区分，不能由同一“重试”按钮绕过版本/费用检查。
- 音频先于正式分镜，流程为 B03→B13→分镜规划→B04/B14→B05→视频/口型→B06/B15→B07/B08→B09/B10→B11/B12；编号是稳定标识，不是执行顺序。B01/B02 在相关操作前重复执行。

## 业务门禁及最小回归场景

| ID | 通过条件 | 执行责任 | 必须验证的阻断/恢复 |
|---|---|---|---|
| B01 ACCESS_ALLOWED | 身份、项目归属、必要复核权限有效；项目未删除 | identity/projects + API/执行用例 | 其他用户访问 Shot/Job/SSE/下载均拒绝；删除后任务不复活 |
| B02 GENERATION_ALLOWED | 输入/Provider能力有效、CNY相关额度同时原子预占、成本上界有效、并发允许、请求幂等 | usage/jobs/调用用例 | 各级¥100不相加，累计测试无上限不绕过额度；未知费用跨月不被释放；重复请求不重复调用 |
| B03 SCRIPT_CONFIRMED | 当前版本结构有效、内容检查满足政策、用户确认 | scripts + workflow | 未确认/旧 revision 拒绝；草稿编辑不修改运行快照 |
| B04 STORYBOARD_CONFIRMED | 当前剧本关联、Shot 输入完整、依赖无环，基于实际 Speech 时长而非仅估算，用户确认 | storyboard + workflow | 过期语音/剧本/循环依赖/缺引用阻断；台词跨 Shot 不因长度超过单镜头被误拦 |
| B05 REFERENCES_READY | 所需参考素材已归档/校验、允许用于生成，版本未过期 | assets/storyboard + workflow | 临时 URL/丢失文件/被阻断参考图不可提交视频任务 |
| B06 CANDIDATE_ACCEPTABLE | 实际媒体有效、当前候选质量通过或获合法复核、安全允许，所需口型 B15 通过 | assets/review + 选用用例 | 不合格候选不能选用；质量确认不能绕过安全或台词/口型硬失败 |
| B07 VIDEO_READY | 全部必需 Shot 有有效选用视频，无未完成的必需依赖、无版本失效 | storyboard/assets + workflow | 一个 Shot 失败或连续依赖过期阻断；无关历史失败不阻断当前集合 |
| B08 REVIEW_PASSED | 选用视频集合的当前审核有效、所有安全阻断已解决 | review + workflow | 替换素材使旧审核失效；旧回调不可借新 Run 推进 |
| B09 AUDIO_READY | DialogueOccurrence每次计划讲述/回放发声覆盖完整，最终音轨/字幕映射正确，B13/B14仍有效 | audio/timeline + workflow | 跨Shot不增加出现次数；计划回放合法、意外重复阻断；视频原声无双重对白 |
| B10 TIMELINE_READY | 固定素材引用可读，轨道/裁剪/时长有效，声音字幕对齐 | timeline | 越界裁剪、丢素材、过期引用阻断；合法混音重叠不误拦 |
| B11 RENDER_READY | 当前 Run 前置门禁有效，编码配置确定，资源与输入快照有效 | timeline + workflow | 取消/删除/版本竞争/缺输出规格禁止启动或提交当前成功结果 |
| B12 FINAL_READY | 输出经媒体探测且归档，输入输出可追溯 | timeline/assets | FFmpeg 成功但输出损坏/上传失败不能完成；仅重试归档不重新生成 |
| B13 SPEECH_READY | 台词/声音/表演版本一致，音频/时长/可信对齐归档；共享批次成员源映射有效 | characters/audio/review + workflow | 批次重生成全成员重验；后句文本未变不证明偏移不变；不能估算替代 |
| B14 PERFORMANCE_PLAN_CONFIRMED | 音轨与 Shot/画内外绑定有效、对白完整覆盖且无抢话，用户联合试听确认 revision | timeline/storyboard + workflow | 试听缺失/映射越界/错人/旧版本阻断；一句跨镜头、一镜头多句合法 |
| B15 LIP_SYNC_READY | 必需画内对白口型/说话人正确、切点同步、非说话者不误动嘴、形象声音一致 | review + workflow | 多角色错配/音节丢失/能力不支持阻断；改正反打需用户确认；明确画外区间无口型任务 |

B02 适用于所有付费模型调用，包括确认之前的剧本和分镜生成；B03/B04 约束后续阶段，不禁止各自前置生成。Provider 每次调用都须通过自身的预算/能力门禁。

B13 在分镜正式确认前执行；B09 为最终混音/字幕完整性，不表示此时才第一次 TTS。台词/口型硬失败不能以普通质量复核绕过；评估方法及容差需实测，缺证据暂停复核。数据与映射见 [音画架构](./dialogue-timeline.md)。

旧 Run 的历史素材可以保留；首期不提供绕过过期依赖继续自动成片的开关。需要恢复必须确认版本、修复依赖或创建新 Run；用户明确创建的历史 Timeline/Render 保持固定输入，不被当前编辑改写。

## 工程门禁

| ID / 截止点 | 通过条件 | 证据 |
|---|---|---|
| E01 进入模块开发 | 范围、职责、数据所有者、接口及失败/版本语义已明确 | 本文/边界、对应 ADR 与任务验收；工程初始化不要求全部 Provider 定案 |
| E02 代码合并 | 类型/lint/边界检查、契约生成一致、相关单元/集成测试、受影响构建通过 | CI 结果；禁止削弱测试使门禁通过 |
| E03 开放真实 Provider | 能力/成本/幂等/下载/取消及普通话单/多角色口型、连续音轨/固定文本实测，预算恢复与安全落实 | research、合约/故障测试、真实音画样本；不得盲重试，普通配音不算 lip-sync |
| E04 开放用户流程 | 联合试听/切点/画内外/过期影响可见，loading/empty/error/权限/冲突/取消可恢复、键盘布局可用 | 浏览器与关键 E2E，覆盖跨镜头/多角色轮流；明确未覆盖场景 |
| E05 生产发布 | 迁移/最小权限/真实配置/健康检查/退出/备份恢复/告警/到期清理保护通过 | 本地RPO24h/RTO4h仅待验目标、1000注册非并发容量；无邮件不公开注册；同盘备份不保证故障恢复 |
| E06 标记迭代完成 | 能力验收和失败路径通过，接口/文档/记忆同步，待人工验证项明确 | 迭代记录及 TODO；不把 Mock 成功当成真实模型验收 |

合并与发布是不同门禁：文档-only 变更检查链接与一致性即可，无需不存在的应用构建；Mock 功能可合并，但不等于允许真实生成或生产发布。生产阈值和容量实测未完成时保持 BLOCKED。

## 变更规则

门禁变化需记录原因、影响模块、策略版本、历史批次适用方式和测试场景，并随同一 PR 更新正式资料。历史证据保留原政策版本；当前使用/发布检查现行安全和访问政策，不能用旧审核永久绕过现行限制。
