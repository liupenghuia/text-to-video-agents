# ADR-005：评审收敛、额度与本地编码基线

日期：2026-10-13。状态：Accepted（按用户委托固化设计，尚未实现或运行验证）。关联 [清单](../product/checkList.md)、[范围](../product/scope.md)、[I002 交付](../iterations/I002-foundation.md)。

## 决策来源

用户明确：测试累计预算暂不设上限、人民币结算、各级额度 ¥100、约1000注册用户总量、没有云服务器而先本地运行、数据保留一个月、容量/恢复目标委托建议。用户已要求执行决策回写与一致性修正。

其余下列数值与操作细节是委托下的首期可配置默认值，不声称用户曾逐条给出，也不代表真实 Provider 可以实现。已有口型/多角色/固定台词要求不降低。

## 产品默认值与运行目标

- 写实剧情、9:16/720p、默认60秒、主验收30～60秒、产品上限120秒；每集最多30 Shot，项目最多6个主要角色，同镜头最多2名对白角色轮流。非对白角色不等于对白能力增加。上限通过后端配置提供，真实开放能力是产品与实测能力的交集，1080p/其他风格与年龄阶段变化后续。
- 支持角色参考上传/生成、衣装/发型场景变体、Agent 建议并由用户调整的表演/画内外安排、真实音频+卡片/参考图时间轴预览；MP4、可选烧录字幕和独立字幕下载。
- 邀请/引导式账号，平台统一 Provider 配置，用户自己素材的质量复核、管理员安全/费用核对；公开注册、邮件及厂商账号均未接入。
- 1000是注册规模规划，不是活跃并发保证。当前本地 Compose，无云资源采购；并发/排队参数由负载及厂商测试再定。
- 本地单项目10 GiB、实例素材50 GiB为存储保护初值，超过暂停新归档/上传，不能自动删在用数据；备份占用另计，并要求磁盘剩余空间检查。不是1000用户生产容量。
- 每日备份，RPO≤24小时、RTO≤4小时为演练目标；备份必须包含数据库、对象引用和实际素材，单机同盘副本不保证故障恢复。生产需独立备份位置及实测。

## 额度与人民币账本

| 额度 | 默认值/周期 |
|---|---|
| 用户 | 每个 UTC 自然月 ¥100 |
| Project | 项目累计 ¥100 |
| Episode | 本集累计 ¥100 |
| GenerationRun | 本轮累计 ¥100 |

所有相关层同时检查，不相加；无 Run 的剧本/语音前置调用仍检查用户/项目/集及一次操作上限 ¥100。累计测试总预算不设上限，不等于绕过以上额度或无限重试。调额是显式管理员操作，审计旧值/新值，不自动因失败提高额度。

CNY金额用精确值，保留原始币种和兑换/报价依据，不预设实时汇率；预占与账单绑定原周期，跨月仍结算到原周期，不能在月切换时释放未知费用。管理员上调额度后仍受实测成本上限和具体测试计划约束。

本轮不授权立即发起外部收费。每个真实测试/业务调用必须有明确输入、次数/成本上界和可核对记录；未知结果不自动再提交。超过默认 ¥100 的单条目标链路先告知并显式调额，不裁台词或降低口型要求凑预算。

## 30天保留与引用释放

“一个月”转换为可配置30天。媒体创建后默认 expiresAt=创建时间+30天；用户明确延期/保留会记录新的到期，不因普通访问或重试悄悄续期。确认规划/历史成片引用不修改底层文件到期。

- 到期前显示提示和下载/延期入口；到期后将相关规划/历史素材标为 EXPIRED，不再允许普通选用/下载或新 Job 引用。历史记录可追溯但不能承诺文件永久可播放。
- 清理先处理到期引用根，显式释放失效引用，再检查其他未到期保留根与运行租约，才能删除对象。未到期根确需源素材时须一并显式延期，不能新建引用偷偷使已过期素材永久保留。
- 执行中的已授权读取暂缓物理清理，有界任务期限/租约保证不无限延长；删除 Project 先取消新工作，再按引用根清理。删除不是删除未知账单。
- 失败/候选/临时媒体也按30天默认归位；临时渲染文件任务结束即清理。自动永久清理必须在实现并测试引用/延期/运行保护后才启用，本轮不删除任何数据。
- 审计、版本摘要、未核对费用不按媒体期限误删；其具体保留期上线前确定。备份保留30天为本地初值，过期媒体不得因恢复被重新开放，恢复后重跑到期核对。

## 修正 ADR-002/003 的执行语义

1. Run 首次绑定剧本并追加首次确认的语音/规划快照属于同一 Run 正常推进；替换已确认或执行过的输入才新建 Run，旧 Job 不重绑。
2. Attempt 失败、Job 未终态可内部重试；FAILED 的可恢复工作可建关联续办 Job，复用原外部任务/结果。CANCELLED 不自动恢复，须用户显式新意图；费用核对与取消独立。
3. 请求幂等按用户/操作/key/payload控制重复提交；内容缓存仅为可选择复用，不能永久禁止相同输入的新候选。主动重生成建立新意图/快照实例、重新预占。
4. 共享语音重生成后新建 SpeechBatchVersion，整批对齐并验证消费者；同文本也可能因源偏移/表演变化失效。DialogueOccurrence独立记录讲述/回放，跨Shot不重复计数。
5. Shot活动意图去重、选用revision检查、取消/删除与阶段推进事务校验；不持有数据库锁等待外部生成。
6. 保存非敏感Prompt模板/编译/适配/模型参数、输入版本、音画区间和执行/账单/审核引用；追溯输入不是承诺像素级重复。
