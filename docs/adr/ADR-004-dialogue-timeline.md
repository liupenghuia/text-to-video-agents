# ADR-004：对白音频先行与跨镜头时间轴

日期：2026-10-13。状态：Accepted（用户确认的设计，尚未实现）。

## 决策与原因

首期普通话角色对白短剧，要求画内口型同步、同镜头多角色轮流对白、跨镜头/集的形象与声音一致、确认台词逐字保留。每句表演允许变化，预设音色身份固定；同时说话/样音定制/旁白短片后续扩展。

对白独立于 Shot，先生成实际音频，再规划与联合确认分镜/对白时间轴。一台词可跨 Shot，一个 Shot 可有多句；通过不可变规划、AudioClip、ShotPlacement 与 SpeechVisualBinding 关联，按时间交集生成口型输入。

替代原“视频通过后再做对白音频”的默认流程及单 Shot 单台词假设。拒绝仅配音替代口型、估算时长直接用于正式生成、视频模型自由改词、未经确认改成正反打。

## 影响与验证

后端增加项目级角色版本、Dialogue/Speech/Alignment、规划与音画 binding；前端提供角色声音、台词表演、实际时长和联合试听确认。音频提前到 I004，真实 TTS/lip-sync 在 I005 验证；I006 完成最终审核/渲染。

详见 [音画架构](../architecture/dialogue-timeline.md)；[ADR-002](./ADR-002-version-confirmation.md) 的第二次确认扩展为分镜与表演时间轴联合确认；Job/Outbox 机制继续使用 ADR-003。验证跨镜头连续声轨、画内/画外正确处理、多角色口型、台词与角色一致性、版本失效和切点同步。
