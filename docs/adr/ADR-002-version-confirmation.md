# ADR-002：固定输入版本与两次创作确认

日期：2026-10-13。状态：Accepted（设计选择，未实现）。

## 背景与选择

剧本修改、连续镜头依赖和晚到结果可能导致生成错配。选择可编辑草稿、不可变确认版本、固定输入 GenerationRun；默认确认剧本和分镜后自动执行，遇阻断暂停。

经 [ADR-004](./ADR-004-dialogue-timeline.md) 补充：第二次确认包含实际对白试听、分镜与表演时间轴；生成语音在分镜正式确认之前。Run 后续阶段绑定不可变确认快照，不改变已运行 Job 的输入。

经 [ADR-005](./ADR-005-coding-baseline.md) 澄清：同Run首次确认后续阶段正常追加快照；替换已经确认或执行过的输入才新Run，不能把每次正常确认当作取消旧Run。

候选先审核再选用；首次可自动选用，通过后续人工替换；Shot 依赖显式记录并传递失效。恢复、重生成和选用分别建模；Episode 是一集，不是执行版本。

放弃直接覆盖旧素材、Job 读取实时草稿、所有镜头无依赖并行和静默重做依赖镜头，避免不可追溯结果与意外费用。

## 影响与验证

需输入快照、乐观并发、依赖图、版本审核和固定 Timeline。首期一个 Episode 同时一个活动完整 Run。验证旧 Job 晚到、确认竞争、替换上游素材、独立镜头保留、审核失效和成片历史不变，见 [范围](../product/scope.md) 和 [门禁](../architecture/gates.md)。
