## 已接受的设计约束

以下是设计基线，尚未实现；完整说明以本表后的范围、架构、门禁与 ADR 入口为准。

- frontend/ 与 backend/ 独立依赖、锁文件；根目录不使用 pnpm workspace 或公共 packages/。后端 API/Worker 分进程，共用业务模块。
- Vue/Vite 前端；NestJS/Prisma/PostgreSQL 后端；Redis/BullMQ 调度；REST/OpenAPI/SSE 契约；私有对象存储、FFmpeg、Docker Compose。
- 单部署多用户，项目归属和用户/管理员分权；开发团队协作不等于首期提供组织协作或支付功能。
- 默认确认台词→实际语音/对齐→按时长分镜→联合试听确认→视频/口型/审核→成片；固定阶段快照，旧结果不得覆盖新选择。
- 首期普通话角色对白短剧，单/同镜头多角色轮流口型同步；形象与预设声音跨镜头/集一致，逐句表演可变但确认台词不改写。旁白/样音/多语言/同时说话后续扩展。
- Dialogue/Speech 不绑定单 Shot，通过 AudioClip/ShotPlacement/画内外 binding 关联；实际时长规划，语音变化使相关规划/口型/字幕待更新。
- 成片以灵活、真实、自然的表演与叙事节奏为质量目标；镜头不得为台词边界机械切换。自然度/衔接由已实测策略或人工复核留证，不能以未经验证的自动分数放行，且不覆盖台词/口型/安全硬失败。
- 连续镜头显式记录依赖；单 Shot 重生成可能使下游过期，需要确认影响范围。
- Outbox、幂等、租约与恢复；Provider 提交结果未知先核对，不盲目再次付费调用。
- 费用保护先于真实 Provider，取消不保证停止收费；质量确认不能绕过安全阻断。
- Provider 厂商、审核阈值和容量必须实测，尚未选定或验证，不据此宣称可上线。
- 2026-10-13 明确：所有付费调用先预算预占，候选先审核再选用，一个 Episode 同时一个活动完整 Run；依据为下方 scope/gates 与 ADR-002/003，尚无运行验证。
- 用户明确CNY、各级¥100、累计测试预算不限、约1000注册总量、先本地、保留一个月；委托初值为用户月/项目/集/Run各¥100、30天媒体、项目10GiB/实例50GiB、每日备份/RPO24h/RTO4h。容量/恢复均未实测，不自动付费或上线。
- 同Run首次确认后续阶段正常追加，替换已确认输入才新Run；FAILED显式续办与CANCELLED新意图区分，请求幂等不永久禁止同内容重生成。依据ADR-005。
